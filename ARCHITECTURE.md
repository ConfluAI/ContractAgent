## 四、BRANCH_SPEC 配置驱动

```
  BRANCH_SPEC = {
      "civil": {                  "labor": {
          priority: 2,                priority: 1,
          label: "合同通用规范",        label: "劳动法律规范",
          bridged: [{                 bridged: [{
              primary: civil_code,        primary: labor_contract_law,
              secondary: interp,          secondary: labor_contract_regulation,
              primary_k: 2,              primary_k: 3,
              secondary_k: 2,            secondary_k: 3,
              bridge: civil_bridge,       bridge: labor_bridge,
          }],                         }],
          standalone: []              standalone: [
                                      ],    {collection: labor_law, k: 2},
                                  ]      }

     ┌──────────────────────────────────────────────────────────┐
     │                                                          │
     │  加新领域只需加一条:                                        │
     │                                                          │
     │  "lease": {                                              │
     │      priority: 1,                                        │
     │      label: "租赁法律规范",                                 │
     │      bridged: [{ primary: lease_law, secondary: ... }],  │
     │      standalone: [...],                                   │
     │  }                                                       │
     │                                                          │
     │  代码零改动。r.search(q, branches=["lease","civil"])        │
     └──────────────────────────────────────────────────────────┘
```

## 五、调用场景路由

```
  用户输入 ──→ Dispatcher (上游 LLM) ──→ branches 参数 ──→ Retriever

  ┌──────────────────────┬──────────────────────┬──────────────────────┐
  │                      │                      │                      │
  │  劳动合同相关          │  纯民事合同            │  混合/未知             │
  │  "拖欠工资..."         │  "货款纠纷..."         │  "合作协议..."         │
  │                      │                      │                      │
  │  branches=[           │  branches=[          │  branches=[          │
  │    "labor",           │    "civil"           │    "labor",          │
  │    "civil"            │  ]                   │    "civil"           │
  │  ]                    │                      │  ]                   │
  │                      │  civil_k 自动放大      │  (开发期兜底)          │
  │  civil 做参照适用       │  (它是唯一依据)        │                      │
  └──────────────────────┴──────────────────────┴──────────────────────┘
```
